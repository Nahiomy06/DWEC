Glosario de Bootstrap 5

Diccionario de términos, clases utilitarias, abreviaturas y prefijos comunes.

m-*, p-* Espaciado
Margin y Padding General

m = margin (margen exterior).
p = padding (relleno interior).
Los valores van de 0 a 5 (ej. m-3, p-2) o auto.

mt, mb, ms, me, mx, my Espaciado
Abreviaturas de Dirección

t (top/arriba), b (bottom/abajo).
s (start/izquierda en LTR), e (end/derecha en LTR).
x (horizontal: left+right), y (vertical: top+bottom).
Ejemplo: mb-3 = margin-bottom nivel 3.

g-*, gx-*, gy-* Grid / Gutters
Gutters (Espacio entre Columnas)

Define la separación (gap) entre columnas y filas dentro de un .row.
g-3: Espaciado general en X e Y.
gx-3: Espaciado horizontal.
gy-3: Espaciado vertical.
Rango: 0 a 5.

container / row / col Grid
Estructura del Grid

container: Contenedor principal que centra el contenido.
row: Fila que agrupa columnas (usa flexbox).
col: Columna que se adapta automáticamente o según el tamaño especificado (de 1 a 12).

sm, md, lg, xl, xxl Responsive
Breakpoints (Puntos de Ruptura)

Definen a partir de qué ancho de pantalla se aplican los estilos:
sm: ≥576px (Móviles grandes)
md: ≥768px (Tablets)
lg: ≥992px (Laptops)
xl: ≥1200px (Desktops)
xxl: ≥1400px (Pantallas grandes)

d-flex, d-block, d-none Display
Propiedad Display

Controla cómo se muestra un elemento.
d-none: Oculta el elemento.
d-flex: Convierte el contenedor en Flexbox.
d-block: Muestra como elemento de bloque.
Permite combinación responsive (ej. d-none d-md-block).

justify-content-* / align-items-* Flexbox
Alineación Flexbox

justify-content-*: Alineación horizontal (center, start, end, between, around).
align-items-*: Alineación vertical (center, start, end, stretch).

primary, secondary, success... Colores Temáticos
Nombres de Colores Semánticos

primary (Azul), secondary (Gris), success (Verde), danger (Rojo), warning (Amarillo), info (Cian), light (Claro), dark (Oscuro).
Se usan con prefijos: text-*, bg-*, btn-*, border-*.

fs-*, fw-* Tipografía
Estilos de Texto

fs-*: Font Size (de fs-1 más grande a fs-6 más pequeño).
fw-*: Font Weight (fw-bold, fw-normal, fw-light).
text-center, text-start, text-end: Alineación de texto.
