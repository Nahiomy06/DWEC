# Formulario tipo FormTempalate #

1- inportarmos el componente qonde vamos a realizar

2- maqueta del formulario.

3- Se le coloca un nombre o template, #miFormulario="ngForm"

4- crear un evento tipo submit que en este caso se llama (ngsubmir).

5-todos los campos tienen que tener un name y un ngmodel.

6- La funcion devolvera un objeto jason con cada uno de los campos de la funcion.
